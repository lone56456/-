# 坦克大战 · Battle City

一个用原生 HTML + CSS + Canvas 实现的经典《坦克大战》（Battle City）网页游戏，单文件即可运行，无需任何依赖。

## 🎮 玩法

- **目标**：消灭关卡内所有敌方坦克，并保护己方基地（🦅 鹰徽）。
- **移动**：`↑ ↓ ← →` 或 `W A S D`
- **射击**：`空格`
- **暂停**：`P`

## 🧱 地形

| 地形 | 说明 |
|------|------|
| 🧱 砖墙 | 可被子弹摧毁 |
| 🟫 钢墙 | 无法摧毁 |
| 🌊 水域 | 坦克无法通过，子弹可越过 |
| 🌲 树林 | 坦克可躲藏其中，子弹可穿过 |
| 🦅 基地 | 被摧毁则游戏结束 |

## 🚀 运行

直接用浏览器打开 `index.html` 即可，或使用任意静态服务器：

```bash
# 方式一：直接双击 index.html

# 方式二：使用 Python 本地服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 🕹️ 特性

- 3 个关卡，循环递增
- 敌方坦克 AI（随机移动 + 倾向进攻基地）
- 计分系统、生命系统（3 条命）
- 爆炸动画、无敌帧（重生闪烁）
- 纯前端实现，无外部依赖
